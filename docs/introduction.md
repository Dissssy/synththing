# synththing docs

The technical side of synththing: how to drive it from a terminal, write visualizer scripts, talk to it from your own programs, run a server, and how it's built and released. For what the app does, see [synththing.p51.nl](https://synththing.p51.nl); for downloads, the [latest release](https://github.com/Dissssy/synththing/releases/latest).

These pages are the Markdown files in the repository's `docs/` folder, so each one is also readable on GitHub, and "Edit this page" (the pencil at the top) opens it there. `docs/SUMMARY.md` lists them.
