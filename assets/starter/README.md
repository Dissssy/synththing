# Starter pack

What synththing offers to set up the first time it runs (the welcome window): a couple of soundfonts and a few songs to try it with.

The app downloads the soundfonts from this folder on GitHub (pinned to a commit and checked against a SHA-256, see `src/starter.rs`), so they aren't part of the exe; the songs are small enough to be built in.

## Soundfonts

- `GeneralUser-GS.sf2`: GeneralUser GS v2.0.3 by S. Christian Collins, from <https://github.com/mrbumpy409/GeneralUser-GS> (<https://www.schristiancollins.com/generaluser>). Its license (`GeneralUser-GS LICENSE.txt`) allows using it in software projects, and asks sites to host their own copy rather than link to the author's downloads, which is what this is.
- `TimGM6mb.sf2`: TimGM6mb by Tim Brechbill (2004), with changes by David Bolton (2010), as distributed by MuseScore and Debian. GNU GPL version 2 (`TimGM6mb LICENSE (GPL-2.0).txt`). A soundfont is its own source, so this file is also the source.

## Songs

`songs/*.mid` are synththing's own arrangements of public-domain music (Frere Jacques, Beethoven's Ode to Joy, Pachelbel's Canon in D, Grieg's In the Hall of the Mountain King), generated by `cargo run --example gen_starter_songs`. They're under the same license as the rest of the repository (WTFPL). Each instrument has its own channel, so muting one in the app is easy to hear.
